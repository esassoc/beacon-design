Textarea

The inherited Ecology multi-line input, wearing the Beacon skin. Optional auto-resize, packaged with its label and help/error text; form-associated via ElementInternals with a teal focus ring.

Inheritedwcimport '@esa/ecology/esa-textarea';

API

PropTypeDefaultDescription
labelstring''Visible label rendered above the textarea.
valuestring''Current value; mirrored to the form on every input.
placeholderstring''Placeholder shown when empty.
rowsnumber3Initial visible row count.
auto-resizebooleanfalseGrows the textarea to fit content as the user types.
help-textstring''Helper text shown below the textarea.
error-textstring''Error message; replaces help text and turns the field red when present.
size'xs' | 'sm' | 'md' | 'lg''md'Control size.
disabledbooleanfalseDisables interaction.
