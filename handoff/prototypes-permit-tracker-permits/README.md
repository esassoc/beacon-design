# Permits

Source prototype: https://esassoc.github.io/beacon-design/prototypes/permit-tracker/permits/

Every permit on every project in one grid: where it applies, agency, owner, status and dates, each linking to its permit page and its project. Shows permits on active projects by default, or closed or all.
