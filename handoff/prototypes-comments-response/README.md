# Response

Source prototype: https://esassoc.github.io/beacon-design/prototypes/comments/response/

One summary response: its text with guidance + Redraft (one new draft, one-step undo), the comments it answers grouped by submission, and the past responses it was drafted from. Accept plans every linked comment at once, and the burn-down beside it counts down by that many.
