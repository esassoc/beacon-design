# Record actions

Response · source prototype: https://esassoc.github.io/beacon-design/prototypes/comments/response/

![Record actions, desktop](https://esassoc.github.io/beacon-design/handoff/prototypes-comments-response/claude/record-actions.desktop.png)

Phone width: https://esassoc.github.io/beacon-design/handoff/prototypes-comments-response/claude/record-actions.phone.png

More, beside the pager: Edit Details (title and topic, in the New Response dialog) and Delete Response (danger, behind esa-confirm-dialog saying how many comments go back to No Response). Delete returns to the Responses tab.

## Key decisions

- Record actions sit in the page header, not the rail: an esa-dropdown-menu inside the rail card is clipped by the card.
- Delete is not offered once accepted; Reopen first. Response numbers are fixed at creation, so deleting one never renumbers the rest.
- A new topic re-routes the response to that topic's expert while its holder is still Aldo's suggestion.

## Done when

- On R-012, Edit Details to Flight paths re-routes it to Mei Tanaka (dashed). Delete Response returns to the Responses tab without R-012; R-011 and R-010 keep their numbers.
