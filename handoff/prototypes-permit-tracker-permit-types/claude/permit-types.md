# Permit types

Permit types · source prototype: https://esassoc.github.io/beacon-design/prototypes/permit-tracker/permit-types/

![Permit types, desktop](https://esassoc.github.io/beacon-design/handoff/prototypes-permit-tracker-permit-types/claude/permit-types.desktop.png)

Phone width: https://esassoc.github.io/beacon-design/handoff/prototypes-permit-tracker-permit-types/claude/permit-types.phone.png

One card per permit type, linking to its page: level, who issues it (the office for state and federal types; for critical areas, the 320 counties and cities), and typical days to issue.

## Done when

- Each card opens its permit type page.

## Components

- `bcn-key-value` (spoke) · `src/components/bcn/BcnImplementationDialog.astro`
- `bcn-ptc` (spoke) · `src/components/bcn/BcnPermitTypeCards.astro`
- `esa-badge` (hub) · `packages/ecology/src/components/esa-badge.astro` → use `ui-badge` in the Beacon app
- `esa-card` (hub) · `packages/ecology/src/components/esa-card.astro`
