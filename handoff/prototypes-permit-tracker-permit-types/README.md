# Permit types

Source prototype: https://esassoc.github.io/beacon-design/prototypes/permit-tracker/permit-types/

A library of the permit types: each one’s governing law and application needs, and every agency that issues it with its time to issue and past permits. Critical Areas Review links to each city’s and county’s ordinance online, with how review works and the wetland and stream buffer tables, read from the code for five southwest Washington jurisdictions. Rules are suggested by AI, edited and validated by a person, each section badged with its status and history; the Agencies grid flags jurisdictions whose ordinance changed after review, and Check for updates re-reads the code sites. Governing law is editable.
