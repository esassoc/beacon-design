# Title row — Edit details, Add items

Custom Compliance Index list · source prototype: https://esassoc.github.io/beacon-design/prototypes/lists/contractor-field-index/

![Title row — Edit details, Add items, desktop](https://esassoc.github.io/beacon-design/handoff/prototypes-lists-contractor-field-index/claude/title-row-edit-details-add-items.desktop.png)

Phone width: https://esassoc.github.io/beacon-design/handoff/prototypes-lists-contractor-field-index/claude/title-row-edit-details-add-items.phone.png

Edit details (name, description) in the side panel every list uses, and Add items, the drawer an obligation list adds from.

## Key decisions

- The canonical index has no title-row verbs at all; a version has Edit details and Add items.

## Done when

- Edit details opens the side panel with the list's name and description; Add items opens the Add drawer.

## Components

- `bcn-list-actions` (spoke) · `src/components/bcn/BcnListActions.astro`
- `esa-button` (hub) · `packages/ecology/src/components/esa-button.astro` → use `ui-button` in the Beacon app
- `esa-icon` (hub) · `packages/ecology/src/components/esa-icon.astro`
